# Projeto Final — Sistema de Análise de Vendas (exemplo)

Funcionalidades:
- Ler CSV de vendas
- (Opcional) Ler Excel com informações adicionais
- Calcular KPIs e gerar gráficos
- Gerar relatório em HTML

Como executar:
1. pip install -r requirements.txt
2. Coloque `vendas.csv` na pasta (exemplo incluso).
3. python main.py
4. Verifique `outputs/relatorio.html` e `outputs/top_produtos.png`.
