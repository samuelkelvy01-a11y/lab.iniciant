# Análise de Vendas com Pandas

Objetivo: praticar leitura de CSV, análise básica e visualização com Matplotlib.

Como executar:
1. Crie e ative um ambiente virtual:
   - python -m venv .venv
   - Windows: .venv\Scripts\activate
   - macOS/Linux: source .venv/bin/activate
2. Instale dependências:
   - pip install -r requirements.txt
3. Execute:
   - python main.py

Saída:
- Prints no console com o resumo.
- Gráfico salvo em `outputs/faturamento_por_produto.png`.
