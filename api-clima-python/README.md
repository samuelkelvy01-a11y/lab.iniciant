# Consumo de API — Exemplo ViaCEP

Objetivo: aprender a consumir APIs REST com requests.

Como executar:
1. pip install -r requirements.txt
2. python api_cep.py
3. Digite um CEP para consulta.

Observação: troque a API por uma de clima (Open-Meteo, WeatherAPI, etc.) se preferir praticar com dados meteorológicos.
