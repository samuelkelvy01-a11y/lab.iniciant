# Portfólio — SamuelKelvy

Este repositório contém projetos de exemplo para um portfólio de início de carreira em Python, análise de dados e automação.

Projetos:
- analise-vendas-pandas: análise de dados com Pandas e gráficos com Matplotlib.
- automacao-excel-python: criação e manipulação de planilhas com OpenPyXL.
- dashboard-streamlit: dashboard simples com Streamlit.
- api-clima-python: exemplo de consumo de API (ViaCEP).
- projeto-final-ciencia-dados: pequeno sistema que integra leitura de CSV/Excel, KPIs e relatório.

Cada pasta tem instruções para configurar o ambiente e executar os exemplos.
